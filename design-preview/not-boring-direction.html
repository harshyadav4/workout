What if Not Boring built GymFlow

First the direction (fonts, colours, materials), then Home in three states. Open in Chrome or Safari. The fonts load from Google Fonts, so it needs internet once.

Direction: type, colour, materials

The idea

Built like a toy.
Logs like a tool.

Cards are plaques with a lit top edge. Buttons are keys you press down. One colour means "go". One moment, logging a set, gets the sound, the haptic and the spring. Everything else stays quiet so that moment lands.

Display font, pick one

Upper · Heavy A · Bricolage
Upper · Heavy B · Rubik
Upper · Heavy C · Unbounded

Body text and labels stay Inter in every option. The number you lift is always the display font.

Colour, two skins

Graphite
Near-black ground, lit plaques, volt lime for go. Ink on lime: 15:1.
Paper
Warm paper, white plaques, same lime key, deep green for text. 5.4:1 on white.

Materials

A plaque Soft vertical gradient, one bright hairline on the top edge, deep shadow underneath. It sits on the page instead of floating in glass.
Sets: done, done, open, pending

The one moment

Logging a set
6/17
  1. Chip springs to 1.3x and snaps back (CSS spring).
  2. A short click sound, Web Audio, no file.
  3. A 12ms haptic on Android (vibrate API).
  4. The ring fills one notch, the next set slides open.
Sound and haptics are off by default on the web. One switch on Profile turns them on. Nothing else in the app animates on load.
