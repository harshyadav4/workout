One start. One finish.

Warm-up, skill practice, main work and stretching live inside Upper A. One clock and one history entry cover the whole session.

Use the controls below to inspect the proposed Today screen, a session in progress, and the existing exercise settings sheet.

Optional is a choice, not a section

An exercise can be optional in any section. It stays collapsed until included. Leaving it out does not reduce completion or show a missed-work warning. Once included, it joins the session’s targets. Logged sets are always retained.

Keep the useful distinctions

  • Warm-up: general preparation goes first. A bench warm-up set still belongs beside its bench working sets, using the existing warm-up marker.
  • Skill practice: handstand work can come before lifting, as your plan specifies. Its actual holds or reps are recorded.
  • Main work: fillers and finishers keep their timing cues. This is not an automatic superset or rest-timer redesign.
  • Stretching: timed holds after the main work. Time is recorded, without counting stretching as lifting volume or strength records.

Your plan stays recognisable

The main Upper A exercises come from your file. Warm-up and stretching entries here are illustrative additions. The wrist-curl filler is marked optional to demonstrate the proposed control; that is a preview choice, not a change to your saved plan.

Saturday’s optional kickboxing stays a separate optional day. Full / Core / Minimum remain alternative plans; importing them must not schedule all three together.

Import should preserve the structure

The manual builder and AI import would use the same section and optional fields. Warm-up or stretching should not become separate sessions, and extra preparation should not displace the main work because of the current eight-exercise import limit.

No app data is changed by this file. The implementation, import changes and reporting rules follow design approval.
